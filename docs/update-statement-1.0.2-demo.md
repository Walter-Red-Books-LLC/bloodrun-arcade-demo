# BLOODRUN DEMO — update notice

The cabinet is still being worked on. This update adds an automatic update check to the installed demo so keeping up with future builds takes less effort.

If you downloaded an earlier copy from GitHub, you will need to download and install this version once. Those older builds do not contain an updater and cannot fetch this change themselves.

After that, supported installed copies check shortly after launch and periodically while open. Available updates download in the background. Installation waits until you choose **Restart and update**. Choosing **Later** keeps the current session open and offers the update again later. The cabinet remains playable when the update service is unavailable.

On Windows, use the **Setup installer** for automatic updates. The portable executable remains a manual-download option. On macOS, install the application in Applications and run it from there. Source downloads and Git clones are still updated manually.

The Windows build is unsigned, so Windows may show an unknown-publisher or SmartScreen warning.

Separately, the main BLOODRUN development build has moved to **0.9.8**, with the tested Fractures work and Help Guides brought back into the main project, along with the recent arcade cleanup. That work is not all part of this demo update.

This remains the arcade evaluation demo. The larger BLOODRUN archive, Layer II, and the hidden internal runtime are separate work still in development. A version number getting closer to one does not mean those sections are finished—or that they are included in this download.

Thank you for playing, breaking it, and reporting what you find. The machine is getting there.
